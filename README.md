# Pontos de Coleta
O "Pontos de Coleta" é um projeto em grupo por David Lemes, Abner Dias, Bruna Coelho e Lauro Victor para a matéria de Construção de Home Pages do curso superior de TI dos participantes.
## O projeto
Feito em HTML, CSS e JS, o projeto "Pontos de Coleta" mira criar uma página WEB para a localização e procura de locais para o descarte apropriado de lixos incomuns.
